# Выжимка

Транспортный уровень передаёт данные между программами на разных компах с помощью портов. Протокол UDP работает без соединения и не гарантирует доставку или порядок сообщений. UDP быстрый и простой поэтому его используют для коротких запросов и потокового видео. Протокол TCP надёжный и работает с соединением он гарантирует доставку и правильный порядок байтов. Для этого TCP использует номера подтверждения и повторную отправку потерянных кусков. Управление потоком в TCP идёт через скользящее окно чтобы буфер получателя не переполнился. Управление перегрузкой сети включает медленный старт предупреждение перегрузок быстрый повтор и быстрое восстановление. Соединение TCP ставится через трёхкратное рукопожатие а рвётся через флаги FIN или RST. В TCP-сегменте есть порты номера флаги размер окна и контрольная сумма. Главное отличие в том что TCP даёт надёжную доставку по порядку а UDP просто быстрый и без гарантий.
